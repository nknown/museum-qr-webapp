The elab is a space where real scientific experiments can be executed by anyone, anytime, anywhere. Most of the available experiments were designed, built and assembled at Instituto Superior Tecnico and are deployed throughout the whole world.

Some of these experiments are being used in real teaching/leaning context by schools in Europe and in the Americas. Nonetheless, any user on the Internet can enter elab, select one of the available experiments, configure it and see in real time its operations. The resulting data is yours to keep it!

FREE is the software infrastructrure that supports all the experiments, data and operations, and can be integrated with any LMS (such as Moodle).

It follows modern software architecures to allow an easy and efficient design, deployment and execution of experiments.

It is written in python and javascript to allow an easy access (on desktop computers or smartphones) from anywere in the internet.
